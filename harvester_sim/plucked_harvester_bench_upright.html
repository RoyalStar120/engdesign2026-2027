The magnets start inside each other's snap distance. They grab within the first few cycles and stay stuck. This is the corrected Section 8 result.

Corrected gap

Safe, but the gap is so wide that the force barely changes over a cycle. The piezo is never really pulled, so there are no pluck ticks.

Redesign

The big driver magnet pulls the piezo about 0.7 mm once per cycle and releases it. Use “Pull & release once” to see the free ring; in steady shaking the next pull arrives after only 1.1–1.6 piezo cycles.
